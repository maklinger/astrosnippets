# astrosnippets
Code snippets I keep using, eg constants, plotting defaults

## Installation with pip
```shell
pip install git+https://github.com/maklinger/astrosnippets.git
```
or updating:
```shell
pip install --upgrade git+https://github.com/maklinger/astrosnippets.git
```


## Changes and updating version number

1. Update version in astrosnippets/__init__.py
2. Update version in pyproject.toml
3. push news to git
4. new git tag: `git tag v1.1.0 && git push origin v1.1.0`
